# Vulpe para Horizon — mod nativo

Mod nativo de [Horizon](https://github.com/horizon-rust/horizon) que acompaña al shader
[vulpe-horizon](https://github.com/noctivulp-ch/vulpe-horizon). Le pasa al pack, por `frame.mods`, el ajuste fino que
no cabe en las 64 opciones del menú de Horizon y datos del mundo que la API de shaders no da.

Diseño: especificación `mod-nativo.md` de la sala limpia (repositorio de especificación, privado). Estado: en
construcción.
